
# StudySpace - Student Assignment Tracker

## Project Description
StudySpace is a web-based Student Assignment Tracker designed to help students organize their academic responsibilities.

## Developer
Aqsa Yousuf

## Technologies Used
- HTML
- CSS
- JavaScript
- Browser Local Storage

## Requirements
- Visual Studio Code
- Google Chrome or another modern web browser

## Installation
1. Download or clone the project repository.
2. Open the student-assignment-tracker folder in VS Code.
3. Open index.html in a web browser.

## How to Run
Open index.html in your browser.

## Sprint 1 Features
- Add assignments.
- Organize assignments by course.
- Set assignment due dates.
- Choose High, Medium, or Low priority.
- View Upcoming, Due Today, Overdue, and Completed assignments.
- Mark assignments as completed.
- Edit assignments.
- Delete assignments.
- Search and filter assignments.
- Save assignments using localStorage.

## Known Limitations
Assignment information is stored in the browser's local storage. It is not synchronized across different devices or browsers.
